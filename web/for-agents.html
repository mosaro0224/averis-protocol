Averis Protocol

Working capital for autonomous AI agents.

⚠ Currently live on Arc Testnet only. USDC has no real-world value. Mainnet deployment pending audit.

What Averis Does

If you are an autonomous agent with an active funded job and a temporary capital shortfall, Averis lends you working capital against the job receivable. You spend from a controlled pool, complete the job, and repayment happens automatically when the job settles.

You do not need collateral beyond the job itself. You do not need a human co-signer.

5-Step Integration

Step 1 — Check eligibility

GET https://api.averisprotocol.xyz/v1/agents/YOUR_ADDRESS/eligibility

Returns your credit limit, available capacity, and active exposure.

Step 2 — Get a quote

POST https://api.averisprotocol.xyz/v2/credit/quote
{
  "agentAddress": "0xYOUR_ADDRESS",
  "protocol":     "0xACP_CONTRACT",
  "jobId":        "42",
  "requestedAmount": "400000000"
}

Returns approved amount, fee, total repayment, and expiry.

Step 3 — Draw capital (on-chain)

POST https://api.averisprotocol.xyz/v1/credit/fund
{
  "agentAddress":      "0xYOUR_ADDRESS",
  "protocol":          "0xACP_CONTRACT",
  "jobId":             "42",
  "amount":            "400000000",
  "allowedRecipients": ["0xRECIPIENT_1", "0xRECIPIENT_2"],
  "perTxLimit":        "100000000",
  "signature":         "0xSIG",
  "nonce":             1,
  "expiry":            1758000000
}

Returns draw() calldata. Submit this transaction from your wallet to create the spending pool.

Step 4 — Spend from pool

// Call directly on the pool contract:
AverisJobPool.spend(recipient, amount, purpose)

Only allowed recipients, within per-tx limit, before expiry.

Step 5 — Job settles, repayment automatic

When the evaluator calls complete() on the job escrow, the settlement routes through ReceivableRouter → AverisFinancingV2.receivePayout() → vault receives principal + fee → you receive the remainder. No manual repayment step.

Authentication

Mutating requests require an EIP-712 signature in the X-Agent-Signature header:

// TypeScript (viem)
import { signTypedData } from 'viem/accounts'

const sig = await signTypedData({
  privateKey: AGENT_PRIVATE_KEY,
  domain: { name: 'AverisProtocol', version: '2', chainId: 1227 },
  types: {
    AgentAuth: [
      { name: 'agentAddress', type: 'address' },
      { name: 'jobId',        type: 'uint256' },
      { name: 'nonce',        type: 'uint256' },
      { name: 'expiry',       type: 'uint256' },
    ]
  },
  primaryType: 'AgentAuth',
  message: { agentAddress: AGENT_ADDRESS, jobId: JOB_ID, nonce: NONCE, expiry: EXPIRY }
})

// Header format:
// X-Agent-Signature: {agentAddress}:{nonce}:{expiry}:{sig}

Pre-conditions

  • Job must be funded and active on a supported protocol
  • You must be the job provider
  • Job payout receiver must be set to ReceivableRouter before funding
  • No existing financing position on this job
  • Requested amount within advance rate cap and your credit limit
